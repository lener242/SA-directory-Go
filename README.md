#  SaDirectoryGo

**SaDirectoryGo** — это веб-сервис справочника (каталога сервисов/пользователей) со встроенной системой авторизации, чатом и административной панелью, написанный на **Go (Golang)** и **PostgreSQL**.

Проект включает контейнеризацию с помощью **Docker**, автоматическую инициализацию базы данных и встроенную веб-панель **pgAdmin** для удобного управления СУБД.

---

##  Основной функционал

*  **Аутентификация и авторизация (`backend/handlers/auth.go`):** Регистрация новых пользователей, вход в систему и разграничение прав доступа.
*  **Справочник и фильтрация (`frontend/js/filters.js`):** Навигация по каталогу, поиск и динамическая фильтрация записей.
*  **Интерактивный чат (`backend/handlers/chat.go`):** Модуль для обмена сообщениями между пользователями сервиса.
*  **Панель администратора (`backend/handlers/admin.go`):** Управление пользователями, сообщениями и настройками системы.
*  **Полная Docker-инфраструктура:** Готовые конфиги для быстрой сборки бэкенда, базы данных PostgreSQL и UI-клиента pgAdmin.

---

##  Технологический стек

* **Backend:** Go (Golang)
* **Database:** PostgreSQL
* **Frontend:** HTML5, CSS3, Vanilla JavaScript (ES6)
* **DevOps & Tools:** Docker, Docker Compose, pgAdmin 4

##  Инструкция по установке и запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/lener242/SaDirectoryGo.git
cd SaDirectoryGo
```

### 2. Быстрый запуск через Docker Compose (Рекомендуемый)
Убедитесь, что у вас установлены **Docker** и **Docker Compose**, затем выполните:

```bash
docker-compose up -d --build
```

После выполнения команды будут доступны:
* **Веб-приложение:** [http://localhost:8080](http://localhost:8080)
* **pgAdmin (Интерфейс БД):** [http://localhost:5050](http://localhost:5050)

### 3. Локальный запуск бэкенда (для разработки)
Если база данных уже запущена в Docker или локально:

```bash
cd backend
go mod download
go run main.go
```
